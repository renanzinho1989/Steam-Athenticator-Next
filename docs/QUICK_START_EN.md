# Quick Start (EN)

## 1. Install
1. Download the Release `.zip` package.
2. Extract it to any folder.
3. Run `Steam Authenticator Next.exe`.

## 2. First setup
1. Open the app.
2. Go to **New Account**.
3. Enter your Steam login/password and complete the guided flow.
4. Save your revocation code in a safe place.

## 3. Use Steam Guard codes
1. Select an account in **Steam Accounts**.
2. Click **Copy code**.
3. Use the code before it expires.

## 4. Confirmations (trade/market)
1. Open the confirmations screen.
2. Review each action carefully.
3. Approve only actions you recognize.

## 5. Security best practices
- Do not share `maFiles`.
- Keep encrypted local backups.
- Use a strong Windows password.
- Avoid suspicious links and fake login pages.

## 6. Troubleshooting
- App does not open: check antivirus and Windows permissions.
- Invalid code: wait for refresh and try again.
- Login issues: verify password, email/SMS, and authenticator steps.
