# Guia Rapido (PT-BR)

## 1. Instalar
1. Baixe o arquivo `.zip` da versao Release.
2. Extraia para uma pasta da sua preferencia.
3. Execute `Steam Authenticator Next.exe`.

## 2. Primeiro uso
1. Abra o app.
2. Va em **Nova Conta**.
3. Informe login/senha da Steam e conclua o fluxo guiado.
4. Guarde o codigo de revogacao em local seguro.

## 3. Usar codigos Steam Guard
1. Selecione a conta em **Contas Steam**.
2. Copie o codigo atual no botao **Copiar codigo**.
3. Use o codigo antes de expirar.

## 4. Confirmacoes (trade/mercado)
1. Abra a tela de confirmacoes.
2. Revise cada acao com cuidado.
3. Aprove apenas o que voce reconhece.

## 5. Boas praticas de seguranca
- Nao compartilhe `maFiles` com terceiros.
- Mantenha backup local criptografado.
- Use senha forte no Windows.
- Desconfie de links e logins suspeitos.

## 6. Solucao de problemas
- Se o app nao abrir: execute como usuario normal e confirme que antivirus nao bloqueou.
- Se o codigo falhar: aguarde renovar e tente novamente.
- Se houver erro de login: verifique senha, e-mail, SMS e codigo autenticador.
